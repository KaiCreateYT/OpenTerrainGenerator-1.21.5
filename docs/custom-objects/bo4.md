# BO4

BO4 is OTG's advanced structure format, designed for large multi-piece structures like villages, dungeons, and complex branching builds. It uses a plotting system with collision detection and terrain smoothing.

**Key differences from BO3:**

- Each piece is limited to **16x16 blocks** (enforced)
- Structures are **pre-plotted** across chunks before spawning — not force-placed
- **Collision detection** prevents overlapping structures
- **Smoothing areas** blend structures with surrounding terrain
- **No force-spawn** — BO4s can only spawn via CustomStructure plotting
- **No tree spawning** — BO4s can't grow from saplings

Set `CustomStructureType: BO4` in DimensionPresetConfig.ini to use BO4 structures.

---

## File Structure

A `.bo4` file uses the same text format as BO3, with additional BO4-specific settings:

```ini
Author=Builder
Description=Village house variant A
SmoothRadius=6
CanOverride=false
MustBeInside=Village_Center

Block(0,0,0,minecraft:oak_planks)
Block(0,1,0,minecraft:oak_planks)
Branch(8,0,0,false,House_Roof,NORTH,100,5)
```

Optional `.BO4Data` files are compiled binary caches generated by `/otg exportbo4data` for faster loading.

## Settings

BO4 shares many settings with BO3 (Author, Description, SpawnHeight, MinHeight, MaxHeight, DoReplaceBlocks) but adds several unique ones.

### Spawning

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `Frequency` | `int` | `0` | Minimum chunks distance from other copies |
| `FixedRotation` | `enum` | *(empty)* | Force specific rotation: `NORTH`, `EAST`, `SOUTH`, `WEST` |
| `SpawnHeight` | `enum` | `highestBlock` | `randomY`, `highestBlock`, `highestSolidBlock` |
| `UseCenterForHighestBlock` | `boolean` | `true` | Use center of structure for height checks |
| `HeightOffset` | `int` | `0` | Y adjustment after spawn height calculation |
| `IsSpawnPoint` | `boolean` | `false` | Spawn one at world start |

### Collision & Placement

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `CanOverride` | `boolean` | `false` | Can overlap other BO4s |
| `MustBeBelowOther` | `boolean` | `false` | Only spawn under existing BO4 |
| `MustBeInside` | `string` | *(empty)* | Required parent BO4s (comma = OR, space = AND) |
| `CannotBeInside` | `string` | *(empty)* | Excluded BO4s |
| `ReplacesBO3` | `string` | *(empty)* | Suppress blocks in listed BO4s on collision |
| `MustBeInsideWorldBorders` | `boolean` | `false` | Respect world border |

`MustBeInside` supports AND/OR logic:

```ini
# Must be inside A OR B:
MustBeInside=StructA,StructB

# Must be inside A AND B:
MustBeInside=StructA StructB

# Must be inside (A AND B) OR C:
MustBeInside=StructA StructB,StructC
```

### Water Handling

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `CanSpawnOnWater` | `boolean` | `true` | Allow spawn on water surface |
| `SpawnOnWaterOnly` | `boolean` | `false` | Only spawn on water |
| `SpawnUnderWater` | `boolean` | `false` | Ignore water in height checks |
| `SpawnAtWaterLevel` | `boolean` | `false` | Spawn at biome water level |

### Block Replacement

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `DoReplaceBlocks` | `boolean` | `true` | Use replacement system |
| `RemoveAir` | `boolean` | `false` | Strip air blocks from object |
| `ReplaceAbove` | `string` | *(empty)* | Material to place above structure |
| `ReplaceBelow` | `string` | *(empty)* | Material to fill below structure |
| `ReplaceWithBiomeBlocks` | `boolean` | `true` | Replace with biome surface/ground blocks |
| `ReplaceWithSurfaceBlock` | `block` | `GRASS` | Surface block for replacement |
| `ReplaceWithGroundBlock` | `block` | `DIRT` | Ground block for replacement |
| `ReplaceWithStoneBlock` | `block` | `STONE` | Stone block for replacement |

### Smoothing

Smoothing generates terrain slopes around structure edges to blend with the surrounding landscape.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `SmoothRadius` | `int` | `0` | Blend radius in blocks (0 = off, -1 = inherit from parent) |
| `SmoothHeightOffset` | `int` | `0` | Y offset for smoothing area |
| `SmoothStartTop` | `boolean` | `false` | Start smoothing from highest block in column |
| `SmoothStartWood` | `boolean` | `false` | Start smoothing from wood blocks |
| `SmoothingSurfaceBlock` | `block` | *(empty)* | Surface block for smoothing slopes |
| `SmoothingGroundBlock` | `block` | *(empty)* | Ground block for smoothing slopes |

How smoothing works:

1. Identifies edge blocks (solid blocks bordering air)
2. Projects lines outward by `SmoothRadius` blocks
3. Calculates terrain height at line endpoints
4. Creates a linear slope from structure edge to terrain

### Inheritance

BO4 supports inheriting blocks and branches from a parent BO4.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `InheritBO3` | `string` | *(empty)* | Parent BO4 name to inherit from |
| `InheritBO3Rotation` | `enum` | `NORTH` | Rotate inherited blocks |
| `OverrideChildSettings` | `boolean` | `true` | Root controls children's smoothing/height |
| `OverrideParentHeight` | `boolean` | `false` | Child uses own height settings |

### Frequency Groups

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `BranchFrequency` | `int` | `0` | Min chunks between same-name branches |
| `BranchFrequencyGroup` | `string` | *(empty)* | `GroupName:Frequency,Group2:Freq2` |
| `BO3Group` | `string` | *(empty)* | Named frequency group |

## Functions

### Block Placement

Same as BO3:

```
Block(x,y,z,material[,nbtFile])
RandomBlock(x,y,z,block1,chance1[,block2,chance2,...])
Entity(x,y,z,entityName,groupSize[,nbtFile.txt])
```

Coordinates are relative to the BO4 origin. X/Z are typically -8 to +7 (16x16 grid).

### Branching

**Branch(x, y, z, isRequired, name, rotation, chance, branchDepth [, totalChance] [, branchGroup])**

```
Branch(8,0,0,false,HouseVariantA,NORTH,50,5)
Branch(8,0,0,true,RequiredWall,NORTH,100,5)
```

| Argument | Description |
|----------|-------------|
| `isRequired` | `true` = always spawns (100%), only one BO4 allowed |
| `name` | Child BO4 name (without `.bo4`) |
| `rotation` | `NORTH`, `EAST`, `SOUTH`, `WEST` |
| `chance` | Spawn chance (0–100) |
| `branchDepth` | Max recursive depth for this branch (-32 to +32) |
| `branchGroup` | Optional frequency group name |

**WeightedBranch(x, y, z, isRequired, name1, rot1, chance1, depth1 [, name2, rot2, chance2, depth2, ...] [, totalChance])**

Mutually exclusive — exactly one branch spawns based on cumulative chances.

```
WeightedBranch(0,0,0,false,SmallHouse,NORTH,30,5,LargeHouse,NORTH,70,5,100)
```

30% small house, 40% large house, 30% nothing.

## Plotting System

BO4 structures are not force-spawned. Instead:

1. **Root BO4** is plotted at a spawn location
2. **Branches** are evaluated recursively — all positions calculated in advance
3. **Collision detection** runs against other plotted structures
4. **Smoothing areas** are calculated
5. During **chunk decoration**, plotted pieces are spawned as chunks generate

This means BO4 structures can span many chunks and won't overlap with each other.

## BO4Data Files

`.BO4Data` files are compiled binary caches of BO4 configs + blocks. They load ~10x faster than parsing text.

Generate them with:

```
/otg exportbo4data
```

This runs in the background — re-run the command to check progress. Only works in worlds with `CustomStructureType: BO4`.

---

## Rotation

BO4 blocks auto-rotate when placed with non-NORTH rotation. Coordinates transform within the 16x16 grid:

| Rotation | Transform |
|----------|-----------|
| NORTH (0) | `x, y, z` |
| WEST (90) | `z, y, -x+15` |
| SOUTH (180) | `-x+15, y, -z+15` |
| EAST (270) | `-z+15, y, x` |

Block states (logs, stairs, etc.) are also rotated automatically.

## Example: Multi-Piece Village

**Village_Center.bo4** (root):

```ini
Author=VillageBuilder
Description=Village center with branching houses
BranchFrequency=50
SmoothRadius=8
CanOverride=true
OverrideChildSettings=true

# Main plaza blocks
Block(0,0,0,minecraft:stone_bricks)
Block(1,0,0,minecraft:stone_bricks)
# ... more blocks ...

# Branch to house variants
Branch(12,0,-3,false,House_Oak,NORTH,50,8)
Branch(12,0,-3,false,House_Spruce,NORTH,50,8)
Branch(-12,0,5,false,House_Birch,EAST,100,8)

# Required walls (always spawn)
Branch(8,0,0,true,Village_Wall,NORTH,100,3)
```

**House_Oak.bo4** (child):

```ini
OverrideParentHeight=false
SmoothRadius=4
CanOverride=false
MustBeInside=Village_Center

Block(0,0,0,minecraft:oak_planks)
# ... house blocks ...

# Roof sub-branch
Branch(0,4,0,true,House_Roof_Oak,NORTH,100,2)
```

## BO3 vs BO4 Comparison

| Feature | BO3 | BO4 |
|---------|-----|-----|
| Max piece size | ~30x30 | 16x16 (enforced) |
| Spawn method | Force-place | Pre-plot + decorate |
| Collision detection | No | Bounding box |
| Smoothing | No | Yes |
| Inheritance | No | Yes (`InheritBO3`) |
| Frequency groups | No | Yes |
| Tree/sapling spawn | Yes | No |
| Block/Light/Mod checks | Yes | No |
| Extrusion | Yes | No |
| `/otg spawn` | Direct | Plots in spiral search |
